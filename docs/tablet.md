# Tablet (Android e iPad)

La dashboard funziona in qualsiasi browser. Su tablet conviene installarla nella
schermata home, così si apre a schermo intero come un'app.

## Installazione

Apri il link 🔗 del Pitwall (o dell'hub) una volta nel browser del tablet, poi:

- **Android (Chrome):** menu ⋮ → *Aggiungi a schermata Home*. Senza HTTPS
  Chrome crea un collegamento, non un'app installata: si apre nel browser.
  Usa il pulsante ⛶ per lo schermo intero.
- **iPad (Safari):** pulsante Condividi → *Aggiungi alla schermata Home*. Si
  apre a schermo intero senza le barre di Safari.

Il token resta salvato nel browser, quindi dall'icona si apre direttamente la
dashboard.

## In gara

- **Preset "Engineer"** (menu in alto a sinistra): raccoglie i widget utili
  all'ingegnere (distacchi, traffico, carburante, gomme, strategia, rivali, eventi,
  AI, mappa, classifica), senza marcia, giri motore o pedali.
- **☀ Tieni acceso lo schermo:** toccalo una volta a inizio gara. Funziona anche
  senza HTTPS (usa un video muto invisibile se il browser non offre l'API
  dedicata). Si spegne se chiudi o cambi scheda.
- **⛶ Schermo intero:** su Android e iPad.
- **Layout bloccato:** sui dispositivi touch parte bloccato (🔒), così uno
  scorrimento col dito non sposta i widget.
- **Verticale e orizzontale:** il layout si ricompone da solo. In verticale i
  widget piccoli vanno a coppie e quelli grandi a tutta larghezza.

## Modificare il layout

Il layout si modifica solo a schermo largo (oltre 1200 pixel CSS, cioè un PC o
un tablet grande in orizzontale): sblocca 🔒, trascina e ridimensiona. Le viste
strette vengono ricavate da quella larga, quindi restano sempre allineate.

## Limiti

- Senza HTTPS non c'è funzionamento offline: la dashboard serve comunque solo
  con Pitwall raggiungibile.
- Su iPhone Safari non esiste lo schermo intero per le pagine web: usa
  *Aggiungi alla schermata Home*.
